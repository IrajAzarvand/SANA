# هوش مصنوعی پنل SANA — طرح مرحله اول

وضعیت: رابط مدیریتی اولیه؛ API و اتصال مدل هنوز پیاده‌سازی نشده‌اند.

## هدف

فراهم کردن پنل ادمین برای چرخه کنترل‌شده تشخیص پروتکل و پیشنهاد Decoder دستگاه GPS. این قابلیت از مسیر زنده دریافت GPS جدا می‌ماند.

## تغییرات مرحله اول

- `sana-panel/src/pages/AIManagement.jsx`: صفحه مدیریتی اولیه، گردش‌کار و مرزهای امنیتی.
- `sana-panel/src/App.jsx`: مسیر `/panel/ai` با محدودیت نقش `site_admin`.
- `sana-panel/src/components/Sidebar.jsx`: گزینه «هوش مصنوعی» فقط در منوی ادمین سایت.
- `sana-gps/PROTOCOL_REGISTRY.md`: معماری Registry و وضعیت فعلی Decoderها.

## API پیشنهادی برای مرحله بعد

پیشوند پیشنهادی: `/api/ai/`. همه endpointها باید احراز هویت و مجوز ادمین سمت سرور داشته باشند؛ مخفی‌کردن لینک در UI کنترل دسترسی محسوب نمی‌شود.

| Method | Endpoint | کاربرد |
|---|---|---|
| GET | `/api/ai/status/` | قابلیت‌های پیکربندی‌شده و وضعیت backend، بدون ادعای سلامت ساختگی |
| GET | `/api/ai/samples/` | فهرست نمونه‌های خام مجاز با صفحه‌بندی و حذف/ماسک شناسه در صورت نیاز |
| POST | `/api/ai/protocol-detections/` | ثبت درخواست تحلیل و نگهداری نتیجه همراه با شواهد/اطمینان |
| POST | `/api/ai/decoder-drafts/` | ساخت پیش‌نویس Decoder؛ هرگز انتشار خودکار |
| POST | `/api/ai/decoder-drafts/{id}/tests/` | اجرای تست در worker ایزوله با محدودیت CPU، زمان، حافظه و شبکه |
| POST | `/api/ai/decoder-drafts/{id}/approve/` | تأیید انسانی و ثبت audit log |
| POST | `/api/ai/decoder-releases/{id}/rollback/` | بازگشت کنترل‌شده به نسخه تأییدشده قبلی |

این جدول قرارداد طراحی است، نه endpointهای موجود.

## چرخه انتشار ایمن

1. دریافت نمونه از منبع مجاز و ذخیره با محدودیت اندازه/زمان نگهداری.
2. تشخیص پروتکل با شواهد؛ مدل باید بتواند نتیجه «نامشخص» بدهد.
3. تولید پیش‌نویس و تست‌های مثبت، منفی، malformed و fuzz.
4. اجرای کد فقط در محیط ایزوله با دسترسی شبکه خاموش و بدون credentials.
5. بازبینی و تأیید انسانی، نسخه‌بندی و audit log.
6. انتشار کنترل‌شده و قابلیت rollback. Decoder جدید نباید بدون مرحله جداگانه به مسیر live وارد شود.

## امنیت و پیکربندی

- هیچ API key یا secret در React، فایل‌های عمومی `.env` یا Git قرار نگیرد.
- در صورت نیاز به LLM، provider و مدل از تنظیمات امن Backend انتخاب شوند.
- درخواست‌های تحلیل، دسترسی به نمونه خام، تأیید و انتشار در audit log ثبت شوند.
- نمونه‌های خام به‌عنوان ورودی غیرقابل اعتماد در نظر گرفته شوند.
- endpointهای تست/تولید/انتشار تا زمان تکمیل sandbox و مجوزها فعال نشوند.

## دامنه مرحله اول

این PR فقط رابط و مسیر دسترسی frontend را آماده می‌کند. هیچ LLM، endpoint واقعی، تولید کد، تست sandbox یا انتشار Decoder پیاده‌سازی نشده است.
